Welcome to the wonderful world of TypeScript! If you've been writing JavaScript and wondering what all the TypeScript
buzz is about, you're in the right place. Let's embark on this journey together with the classic "Hello World" approach.

## What is TypeScript?

TypeScript is JavaScript's sophisticated cousin – it's a superset of JavaScript that adds static typing to the language.
Think of it as JavaScript with superpowers. Every valid JavaScript code is also valid TypeScript code, but TypeScript
gives you additional tools to catch errors before your code even runs.

Created by Microsoft and first released in 2012, TypeScript has become the go-to choice for building large-scale
applications. Companies like Google, Airbnb, and Slack use it to build robust, maintainable codebases.

## Why TypeScript?

Before we dive into code, let's understand why you might want to use TypeScript:

- **Catch errors early**: Find bugs at compile-time instead of runtime
- **Better IDE support**: Enjoy autocomplete, refactoring, and inline documentation
- **Self-documenting code**: Types serve as inline documentation
- **Easier refactoring**: Change code with confidence
- **Enhanced collaboration**: Types make it clear what your code expects

## Your First TypeScript Program

Let's start with the classic "Hello World" example. Here's how you'd write it in TypeScript:

```typescript
function greet(name: string): string {
    return `Hello, ${name}! Welcome to TypeScript.`;
}

const message = greet("World");
console.log(message);
```

Notice the `: string` annotations? That's TypeScript in action! We're telling TypeScript that the `name` parameter must
be a string, and the function will return a string.

## The Power of Type Safety

Here's where TypeScript really shines. Let's see what happens when we try to pass the wrong type:

```typescript
function add(a: number, b: number): number {
    return a + b;
}

const result = add(5, 10); // ✅ Works perfectly
console.log(result); // Output: 15

// This will cause a TypeScript error:
// const wrongResult = add("5", 10); // ❌ Error: Argument of type 'string' is not assignable to parameter of type 'number'
```

TypeScript catches this mistake before you even run the code. No more mysterious `NaN` results or unexpected string
concatenations!

## Defining Custom Types

One of TypeScript's most powerful features is the ability to define your own types. Here's a practical example:

```typescript
interface User {
    id: number;
    name: string;
    email: string;
    isActive: boolean;
}

function createWelcomeMessage(user: User): string {
    return `Hello ${user.name}! Your account (${user.email}) is ${user.isActive ? 'active' : 'inactive'}.`;
}

const newUser: User = {
    id: 1,
    name: "Alice",
    email: "alice@example.com",
    isActive: true
};

console.log(createWelcomeMessage(newUser));
// Output: Hello Alice! Your account (alice@example.com) is active.
```

With this interface, TypeScript ensures that any `User` object has all the required properties with the correct types.
Your IDE will even autocomplete the properties for you!

## Getting Started

Ready to try TypeScript yourself? Here's how to get started:

1. **Install TypeScript**: Run `npm install -g typescript` in your terminal
2. **Create a TypeScript file**: Save your code with a `.ts` extension
3. **Compile it**: Run `tsc yourfile.ts` to compile it to JavaScript
4. **Run it**: Execute the generated JavaScript file with Node.js

Or use an online playground like the [TypeScript Playground](https://www.typescriptlang.org/play) to experiment without
any setup!

## What's Next?

This is just the beginning of your TypeScript journey. As you continue, you'll discover:

- Advanced types like unions, intersections, and generics
- Powerful type inference that reduces the need for explicit annotations
- Utility types that help you transform existing types
- Integration with popular frameworks like React, Vue, and Angular

So go ahead, write that first `Hello, World!` in TypeScript, and welcome to a more confident way of writing JavaScript.
Happy coding!
